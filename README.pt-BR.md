# Olá, sou gutoqualidade

Desenvolvo software com foco em clareza, testes e facilidade de manutenção.

### Abordagem

- **Manter a simplicidade.** Usar limites claros e acrescentar complexidade quando o problema exigir.
- **Verificar o comportamento.** Testar casos relevantes e medir antes de otimizar.
- **Tornar o trabalho compreensível.** Documentar como executar, as decisões tomadas e as limitações.

### Projeto

[**work-budget**](https://github.com/gutoqualidade/work-budget) — pequena biblioteca Rust para acompanhar trabalhos em andamento e descartar resultados antigos após uma invalidação. Inclui exemplo executável, testes de comportamento, decisão de arquitetura e limitações documentadas.
