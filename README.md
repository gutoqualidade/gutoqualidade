# Hi, I'm gutoqualidade

I build software with a focus on clarity, testing, and maintainability.

### Approach

- **Keep it simple.** Use clear boundaries and add complexity when the problem calls for it.
- **Verify behavior.** Test meaningful cases and measure before optimizing.
- **Make work understandable.** Document how to run it, the decisions behind it, and its limitations.

### Selected project

[**work-budget**](https://github.com/gutoqualidade/work-budget) — a small Rust library for tracking in-flight work and discarding stale results after invalidation. Includes an executable example, behavior tests, architecture decision and documented limits.
